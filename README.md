# Beat the Clock

Beat the Clock is an exploratory Python project for the NFL Big Data Bowl — NYU Edition, studying how quarterback release timing relates to WR, TE, and RB separation on short passes.
The intended coaching tool will compare throwing-time distributions and receiver movement across comparable situations, with play replays to explain any validated patterns.
The project uses the event's public 2021 Weeks 1–8 tracking and PFF data, identifying short passes from play-description labels rather than assuming that total yards gained represent pass depth.
Current scripts are experimental: receiver-target matching and measurement definitions require validation, separation alone does not establish a safe throw, and no final findings or finished visualization are claimed.
